# Стиль `degen` / DOXA: стайлгайд и API

Включается одной строкой в таймлайне: `look: 'degen'`. Тогда index.html убирает тёплую плёнку/виньетку/мерцание (кадр чистый и яркий), зерно почти пропадает, бейджи и субтитры становятся чёрно-жёлтыми, и подгружается библиотека `src/degen/` (сова, терминалы, локации). Эпизоды без `look` рендерятся байт-в-байт как раньше.

Эталоны: `images/doxa/owl.webp` (персонаж), `images/doxa/terminal.webp` (UI). Пример: `template/episodes/doxa/`.

## 1. Язык монтажа (из вирусных крипто-рилсов)
- Жёсткие склейки каждые 1–2 с, без переходов. Внутри шота медленный наезд на 3–7 %.
- **PnL-счётчик** сверху — главный «персонаж» монтажа: огромные цифры Rubik 900 с толстой чёрной обводкой, зелёные в плюсе, красные в минусе. На каждом новом значении — поп.
- Терминал показываем **на весь кадр** — это вставка, как экран Claude в garazh.
- Поворот против → шок крупно (очки сползают, глаза-круги, пот, тревога) → поворот за (памп, тряска, бум) → монтаж богатства под бит.
- Монтаж богатства: каждая локация 2 с, счётчик растёт на порядок, сова танцует (`dance`), деньги падают.
- Панч — возврат в реальность: настоящая цифра, deadpan, одна короткая реплика.

## 2. Сова DOXA (`CHARS.owl`, src/degen/chars.js)
Коричневые перья, хохолок и уши-перья, кремовый лицевой диск, жёлтые глаза под тяжёлыми веками, оранжевый клюв-крючок; чёрный костюм с золотыми кантами и лентой «DDDD» на рукавах (риг `band`). Пиксельные очки «deal with it» надеты **всегда** — это фирменный вид.

Треки `cast.owl.tracks`: `shades` (по умолчанию 1; 0 — снять), `slip` 0..1 (очки сползают; при шоке — сами), `grin` 0..1 (ухмылка), `sweat` 0..1 (пот; при шоке — сам), `puff` 0..1 (перья дыбом; при шоке — сам), `dance` 0..1 (подпрыгивание и покачивание в такт `TIMELINE.bpm`). События: `shock: [[a,b]]` как у всех персонажей. Позы — все пресеты движка (`rest typing fingerUp spread point thumbsUp down …`).

## 3. Терминал prediction markets (`set: 'market'`, src/degen/market.js)
```js
markets: { btc: { cat, title, ends, icon, vol,
  chart: { seed, n, path:[…] },          // история вероятности 0..100
  prob: [{ t, v, dur? }],                // живая вероятность YES (двигает график, цены Yes/No в ¢, крупную цифру)
  select: [{ t, v:'yes'|'no'|'' }],      // выбранная кнопка
  amount: [{ t, v, dur? }], amtMin, amtMax,   // ползунок суммы 0..1
  press: [t],                            // Buy (цена входа фиксируется на первом нажатии → Payout)
  pos: { show:[[a,b]], entry:'12¢', pnl:[{ t, v, dur? }] },
  resolve: { t, outcome:'YES'|'NO' },    // штамп RESOLVED
  rows: [{ name, p }],                   // (опц.) список исходов вместо графика
  alert: [[a,b]], iconBg, iconFg,        // красная тревога; цвета иконки
  cursor: [{ t, v:[x,y], dur? }], clicks: [t] } },
shots: [{ set: 'market', market: 'btc', … }]
```
Точки курсора: Yes (200, 826), No (520, 826), ползунок x = 110 + k·500, y = 936, Buy (360, 1018).
Есть и классический крипто-терминал со свечами и плечом: `set: 'terminal'` + `TIMELINE.term` (src/degen/terminal.js).

## 4. Локации (`set: 'stage'`, shot.back / shot.front)
`roomBack/roomFront` — тёплая ночная квартира (торшер, растения, окно на город, монитор слева; `env.glow: 'yellow'|'green'|'red'`, `env.mess: 1` — бумажки), `yachtBack` — палуба на закате, `clubBack` (`env.flash`), `roofBack` (билборд DOXA), `moonBack` («to the moon»), `moneyFront` — пачки денег + дождь купюр (`env.rain`). `set: 'paw'` — лапа на мышке, клики `events.clicks`.
`sofaBack/sofaFront` — сова на диване смотрит ТВ (свет экрана спереди `env.tv`, вспышка `env.tvflash`, подушка с «D» `env.pillow`, дождь купюр `env.rain`).
`set: 'tv'` — ТВ-трансляция матча крупно: `TIMELINE.tv = { home, away, homeKit, awayKit, clock:[{t,v:сек}], ball:[{t,v:[u,w]}], goals:[{t,team}], final }` — счёт из голов, баннеры GOAL!/FULL TIME, табло «90+N'». Без логотипов клубов — только цвета формы. Пример: `episodes/clasico`.

## 5. Оверлеи и движок
- `pnl: { show:[[a,b]], keys:[{ t, v, dur?, flat? }], y? }` — счётчик (dur — «накрутка», flat — сумма без знака, жёлтым).
- `events.shakes: [[t, px, dur?]]` — удары камеры.
- `shot.cast: [{ who, x, y, s, rot }]` — `rot` поворачивает персонажа вокруг ног.

## 6. Звук
Рецепты `sfx/build.mjs`: `kickLoop hatLoop clapLoop bassLoop` (лупы на `len` секунд, `bpm`, у баса `root`, `notes`), `cash` («ка-чинг»), `riser` (`align:'end'`, `dur`), `alarm`, футбол: `crowd` (`len`), `roar` (`dur`), `whistle` (`blasts:[[d,gap]…]`). Музыка стартует на дропе (резолв/монтаж) и обрывается на склейке в реальность — тишина перед панчем.

## 7. Бренд
Лексика: trade, predict, position, market, probability. Никогда: bet/betting/gamble/casino/ставка/wager. Реальные люди — только текстом вопроса рынка.
